Frequently asked questions.

Useful details before you install.

Does SariPOS work offline?

Yes. The current Android build is designed for local/offline operation. Internet is not required for normal POS use.

Where is my business data stored?

The current Android build keeps its POS data locally on the device.

How do I get a license?

Install the app, copy your SariPOS Device ID from Settings, then message us through Facebook for license activation.

Can I use this for different stores?

Yes. Each installation can be managed using its own SariPOS Device ID and corresponding license record.
